# Deployment Standards
- Hero: 21:9 desktop with an intentional mobile crop around 4:5 or 3:4.
- Content landscape: 3:2.
- Portrait: 4:5.
- Cards / resources: 1:1.
- Slightly reduce saturation and keep skin tones natural; do not wash every image in a green filter.
- Use Clay/Ochre warmth selectively; let composition, texture and light create visual consistency.
- Replace homepage, team, facility and proof imagery with custom TAB photography as soon as practical.
